# Exercise 210-05-notebook

Companion exercise to part 5 of the series "Learning Claude for Microsoft Fabric": "Fabric notebook toolkit: can Claude Code debug a live Spark session?". Runs locally; only the optional step uses your own Fabric workspaces.

> **Status:** In preparation. The full exercise (setup, project, check.py, solution) is published together with the video.

## Task

Work out with Claude from a recorded toolkit session (JSON) what is finished, what is still running and which session was left open.

## What a good result looks like

3 of 3 next actions right, session ended.

## Optional

Repair the notebook in your own dev workspace.
