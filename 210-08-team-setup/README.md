# Exercise 210-08-team-setup

Companion exercise to part 8 of the series "Learning Claude for Microsoft Fabric": "Fabric repo for a team: what belongs in CLAUDE.md, MCP and skills?". Runs locally; only the optional step uses your own Fabric workspaces.

> **Status:** In preparation. The full exercise (setup, project, check.py, solution) is published together with the video.

## Task

Start from an empty folder and build the team setup with Claude: project notes, settings, hook, an MCP server file, a skill.

## What a good result looks like

Every file present and valid, the hook stops a sample call, 0 token patterns in any file.

## Optional

A colleague clones it and starts with their own sign-in.
