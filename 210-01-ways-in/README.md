# Exercise 210-01-ways-in

Companion exercise to part 1 of the series "Learning Claude for Microsoft Fabric": "Fabric CLI, REST API or MCP server: which should Claude Code use?". Runs locally; only the optional step uses your own Fabric workspaces.

> **Status:** In preparation. The full exercise (setup, project, check.py, solution) is published together with the video.

## Task

Five Fabric tasks (run a notebook, find an item across workspaces, change a role, ...). Pick one way in for each (fab, fab api, Fabric Core MCP server) and write an allow list that covers exactly those.

## What a good result looks like

Every task has one way, and the allow list covers those and nothing else.

## Optional

Compare with the portal in your own workspace.
