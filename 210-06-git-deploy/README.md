# Exercise 210-06-git-deploy

Companion exercise to part 6 of the series "Learning Claude for Microsoft Fabric": "Fabric Git integration: should Claude Code edit repo or workspace?". Runs locally; only the optional step uses your own Fabric workspaces.

> **Status:** In preparation. The full exercise (setup, project, check.py, solution) is published together with the video.

## Task

Item definitions, an incomplete parameter.yml and a dry run that applies it. Complete the parameter file so that no dev ID is left after the dry run.

## What a good result looks like

Dev GUIDs found: 0.

## Optional

Deploy to your own dev/test workspace pair and read the binding back.
