# Two answers to the same question

Run 1: about 30 % fewer bikes on weekends (−29.9 %).
Run 2: about 28 % fewer bikes on weekends (−28.3 %).

Decisions that differed, or that I would have made differently:

- Missing days: run 1 used only the days on which every counter reported; run 2 averaged each counter over the days it has.
- Monday 15 September (Knabenschiessen): both runs counted it as a normal weekday. City offices and schools are closed that day, so I'd leave it out.
- Correction factors: neither run applied them. That's what I want, but it was Claude's choice, not mine.

Both runs also said that Mythenquai is the only counter with more bikes on weekends (about +5 %).
