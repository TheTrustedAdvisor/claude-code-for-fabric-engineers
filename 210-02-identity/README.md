# Exercise 210-02-identity

Companion exercise to part 2 of the series "Learning Claude for Microsoft Fabric": "Fabric identity for Claude Code: your account or a service principal?". Runs locally; only the optional step uses your own Fabric workspaces.

> **Status:** In preparation. The full exercise (setup, project, check.py, solution) is published together with the video.

## Task

Three tasks: list the items in a workspace, change a notebook, give someone a role. Enter the smallest Fabric workspace role for each in roles.yaml, with the source.

## What a good result looks like

Viewer, Contributor, Member.

## Optional

Run fab auth status on your own machine and note which account Claude Code would act as.
